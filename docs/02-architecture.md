# 架构与计薪口径

## 分层

```text
QML 页面
  └─ 绑定 WorkTimer 属性与操作
       ├─ 读取 NetworkClock 校准时间生成当前班次快照
       ├─ 用整数分计算工资
       └─ 通过 QSettings 保存设备本地配置
NetworkClock
  ├─ 异步 DNS + NTP/UDP 网络校时
  └─ 使用单调时钟推进校准后的时间；失败时沿用上次校准或设备时间
```

- `src/ui/`：自适应主页与工资/排班设置页；颜色由 `Theme.qml` 统一维护。
- 2026-10-08 视觉重做：共享浅色面板主题，`PixelPanel` 绘制阶梯角/双描边，`PixelDigits` 绘制实时5×7点阵数字，`PixelIcon` 自绘跨平台图标，`PixelMeter` 展示业务进度；`HomePage` 使用场景/并排主卡/三列状态面板，窄屏纵向重排。首页快捷设置 `QuickScheduleCard` 调用现有 `setShiftTimes` 与 `applySettings`，时薪仅在原工资模式为时薪时可编辑，月/日薪折算值为只读并链接完整工资页。
- `src/app/WorkTimer.*`：QML 接口、计时快照、排班/休息区间处理和本地持久化。
- `src/app/NetworkClock.*`：异步 NTP 校时、同步状态和校准时间推进。
- `src/main.cpp`：创建 Qt Quick 应用并加载 QML 模块。
- 桌面与 Android 共用 QML 和计算代码，分别由 Qt Kit 构建。
- 首页精力血条按有效工作进度从 100% 递减至 0%，颜色由绿转黄再转红；`AnimatedSprite` 和疲劳文案共用同一进度。图片帧固定为 3 列 × 2 行，每格 512×512。
- `WorkTimer` 按已完成的排班日累积打工经验，每日 20 XP、每级 500 XP；用户可编辑历史累计上班天数，当前班次按有效工时预览未结算经验，并将累计天数与处理日期保存在 `QSettings`，避免重启后重复记账。
- Windows 桌面应用顶栏图钉通过 `Qt.WindowStaysOnTopHint` 切换窗口置顶，并把开关保存在 `QSettings` 的 `ui/windowPinned`；Android 不请求跨应用悬浮窗权限，也不显示此按钮。

## 计薪规则

1. 上下班时间相同视为无效设置；下班时间早于上班时间时视为次日下班。
2. 工资支持月薪、日薪、时薪：月薪按月计薪天数 × 单日有效工时折算；日薪按单日有效工时折算；时薪直接使用。
3. 月薪默认使用 21.75 个计薪日，可在设置中调整。
4. 休息区间从班次墙钟跨度中扣除；已赚金额和进度按有效工时区间计算。
5. 金额内部以整数分保存与显示。每次刷新根据网络校准时间重新计算，不累计定时器误差；NTP 失败时沿用最近一次校准，首次联网失败时使用设备时间。
6. 休息日显示下个排班日的倒计时；没有选择工作日时显示配置提示。
7. 排班支持固定周与大小周；大小周分别配置工作日掩码，并以用户指定的基准周周一及周类型为锚点，每过一周自动切换。
8. 年历公告的法定放假日覆盖固定周/大小周排班并作为休息日；官方调休上班日覆盖周排班并按用户班次计算。节假日工资按实际排班工时估算，不另算法定节假日或加班倍率；金额为税前个人估算，不计算税费、社保和公积金。
9. 经验按配置的排班日累计；新经验系统从首次启动当天开始记录，每完成一个排班工作日获得 20 XP，500 XP 升一级，当前班次的经验随有效工时预览增长。

## 数据与生命周期

- `QSettings` 保存工资模式、金额、月计薪日数、班次、休息区间、固定周/大小周工作日掩码及大小周锚点、已上班天数与经验处理日期，以及 Windows 置顶开关。
- Windows 窗口关闭或 Android 应用进入后台时不依赖后台 tick；回到前台即刷新并发起网络校时。
- Android 申请普通 `INTERNET` 权限以查询 NTP 时间；不需要运行时授权弹窗。

## 验收行为

- 改工资和班次后，首页显示的时薪、今日工资、倒计时和进度与设置一致；法定放假日停班且工时/工资/经验不增长，调休上班日照常按个人班次累计。
- 精力血条随有效工时下降、颜色逐步变暖，牛马姿态与疲劳文案同步；下班后精力为 0%。
- 蓝色经验条随当前工时和累计排班上班日增长；完成班次后经验保存，应用关闭重开不会重复奖励。
- 可在设置中录入历史累计上班天数，等级/经验随录入数值更新；之后每完成一个配置的排班班次自动增加一天。
- 设置页显示网络校时状态；网络可用时倒计时使用校准时间，断网时沿用上次校准或设备时间。
- 午休时倒计时继续减少，工资、有效工时进度和精力消耗暂停。
- 设备休眠或应用切后台后恢复，显示按最新网络校准时间推进。
- Windows 点击标题栏图钉后，窗口保持在其他普通窗口上方；再次点击可取消，重新启动后沿用上次置顶状态。
- Windows 与 Android 使用相同输入时，主要展示与工资口径一致；需要分别进行设备交互验收。

## 中国法定节假日倒计时（2026-10-08）

- `ChinaHolidayCalendar` 独立加载 `assets/china-holidays.json`，校验版本、日期区间、年度及调休日期。资源通过 CMake 嵌入，离线可用。
- `WorkTimer::refresh()` 将 `NetworkClock` 的当前时间传给年历，暴露只读 `holiday` 展示模型；`HolidayCountdownCard.qml` 负责首页卡片和全年详情弹层。`scheduleOverride()` 让公告放假日覆盖固定周/大小周，官方调休上班日则恢复为工作日；统一的班次计算让工资、计时、进度、经验与历史遵循该结果，假期表本身不写入用户个人排班设置。
- 年历以北京时间 UTC+8 零点为边界；开始日包含在内，结束日次日零点不包含在内。当前假期优先显示剩余时间；否则选取下一个假期。按剩余毫秒向上取整为秒，避免最后一秒提前显示零。
- 2026 年数据来自国务院通知，含连续放假区间和调休上班日。最后已公布年度之后仅补充下一年元旦的法定日期，标记连休/调休未公布；超过该日期不推测春节等农历假期，显示年历待更新。
- 数据按应用版本发布，无自动抓取年历服务。新增年度前需核对国务院通知并更新 JSON/来源；详见 `05-china-holiday-countdown.md`。
- 跨午夜班次若进入法定放假日，在假期当天零点截断前一日班次，避免假期时段继续累计工时与工资。
- `WorkHistoryStore` 加载后修正旧版假期误结算：先备份原文件，保留日期/任务并归档原快照，再取消班次结算和收入/工时；列表、统计读取与写入入口都有假期日期约束。重复加载不重复迁移，保存失败保留原数据并报告存储错误。
