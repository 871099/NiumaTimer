# 牛马打工计时器 v0.1.0

首个 Windows x64 Release 版本，使用 Qt 6.8.3 / MSVC 2022 构建。

## 下载与启动

下载 `NiumaTimer-0.1.0-windows-x64.zip`，完整解压后双击 `NiumaTimer.exe`。请保留同目录的 DLL、平台插件和 QML 目录。运行库安装程序随包提供，如提示缺少 MSVC 运行库，请运行包内的 `vc_redist.x64.exe`。

设置、任务和历史保存在当前 Windows 用户的数据目录中，更新程序时继续读取现有数据。旧版误结算的法定假期班次会先备份历史文件再修正，保留任务和原始班次快照。

## 已包含功能

- 下班倒计时、月薪/日薪/时薪估算和休息区间。
- 固定周与大小周排班、网络校时、设置保存与窗口置顶。
- 牛马疲劳动画、精力血条、蓝色经验条与累计上班天数。
- 任务、日/周/月统计、历史记录、成就和外观。
- 法定假期倒计时、官方放假日停班和调休补班。
- 国庆旧历史误结算的自动修正与备份。

## 验证与限制

- 日历及历史迁移回归检查通过，Windows Release 构建与打包启动检查通过。
- 官方年历覆盖2026年；2027年暂收录元旦法定日期，连休/调休待正式公布后更新。
- 旧经验总数没有逐日来源，本次历史修正不从手填累计天数中反推扣减。
- Android 源码已包含，当前未发布 APK；完整手机和各页面交互仍待实机验收。
- 工资为按排班工时计算的税前估算，不计算税费、社保或加班倍率。
