# 牛马打工计时器完整产品实施方案

状态：用户已确认实施；多页面及共享历史层已落入代码，Windows 已构建和启动。完整交互验收、Android 构建及实机验收仍待完成（2026-10-08 核对）。

## 产品目标

以用户提供的 Android / Windows 产品图为验收基准，在现有 Qt 6.8 + QML 工程上完成同一套业务能力与跨尺寸界面。Windows 使用左侧导航，Android 使用底部导航；两端共享工资、排班、任务、统计与成长数据。保留当前已完成的大小周、精力血条、经验条、历史上班天数输入和网络校时。

## 页面与功能范围

### 首页

- 顶部显示牛马头像、等级、累计经验和蓝色经验进度条。
- 以办公室场景与疲劳牛马为视觉焦点，继续使用现有原创素材并补齐所需姿态/装饰。
- 主要区域显示下班倒计时、今日已赚工资及时薪/工时、本日进度条与阶段时间线。
- 状态区显示精力、自由和摸鱼三条数值；窄屏重排为纵向卡片，不能缩到不可读。
- 提供今日任务、工资设置、工作时间设置的快捷入口。

### 任务

- 显示上班、休息/摸鱼、会议或自定义工作阶段、下班等今日节点，并与工作时间设置的时间线联动。
- 支持添加、编辑、删除当日自定义事项及完成标记；完成标记不改变工资计算。
- 当前节点、已完成节点和未开始节点有不同的视觉状态。

### 数据统计

- 按日、周、月查看工作时长和工资估算，包含每日曲线/柱图、周期合计和工作日数。
- 新增本地历史记录，处理跨午夜班次、休息时段、大小周以及应用关闭后补结算，避免重复记账。
- 明确显示统计口径为配置排班下的个人估算；不引入云同步或税务结算。

### 工资设置与工作时间设置

- 分成产品图对应的独立入口；保留月薪/日薪/时薪、计薪天数、上/下班时间、休息区间、固定周/大小周工作日和轮换锚点。
- 工资页负责工资口径与金额；工作时间页负责班次、排班及今日阶段节点。
- 保留已上班天数录入与网络校时状态/立即同步入口。

### 成就图鉴

- 以累计上班日、等级、连续排班完成记录生成已解锁/未解锁徽章，例如首个工作日、累计 10/30/100 天和等级节点。
- 徽章由本地工作记录推导；不要求账号或联网服务。

### 外观换装

- 提供牛马服饰/配色选择和可预览的解锁状态；累计工作日或成就可解锁装扮。
- 补齐与现有疲劳精灵图一致的透明姿态素材，避免直接拉伸产品图中的整张拼版。
- 选择结果保存在本机，首页动画与图鉴保持一致。

### 关于

- 显示版本、使用说明、计时/估薪口径、隐私与本地数据说明、素材来源说明。

## 状态条口径建议

产品图展示了 HP、自由值和摸鱼值，但没有写明三者算法。为让它们可观察且和现有排班一致，建议按以下口径实现：

- HP/精力：100 减去当前班次有效工时进度，随班次推进下降，休息区间暂停。
- 自由值：当前班次有效工时进度，达到下班时为 100；休息区间暂停。
- 摸鱼值：当天已经过的配置休息时长占当天计划休息时长的比例，休息时递增，最高 100，每天重新计算。
- 经验：沿用每完成一个排班工作日 20 XP、每 500 XP 升一级；进行中的当天经验仅作预览，完成后结算。

## 架构落点

- `WorkTimer` 继续负责排班、倒计时、工资、班次进度与三条状态的计算接口；`NetworkClock` 独立负责校时。
- 新增 `WorkHistoryStore` 独立保存每日已结算工资、工时、班次和任务状态，采用带版本号的数据结构、缺省值和旧数据兼容处理。
- 成就基于历史记录和经验数据派生；外观选择与解锁记录本地保存。
- QML 拆为共享 `AppShell`、导航组件、首页卡片和独立页面，避免把所有路由与页面继续堆进 `Main.qml`。
- 更新 UML 的组件图、页面/数据类图、计时与历史结算时序图、工作状态机和双平台部署图。
- 不引入第三方 UI 插件；图片素材保留来源/生成说明。

## 分阶段实施与验收

### 阶段 1：应用壳与首页

交付桌面侧栏、手机底栏、顶部等级经验条、场景主视觉、倒计时/工资卡、进度时间线、三条状态条和设置快捷入口。验收窗口缩放时卡片重排、倒计时刷新、XP/HP/自由/摸鱼数值按上述口径同步，菜单能切换到现有设置页。

### 阶段 2：任务与设置页

交付任务时间线和事项维护；拆分工资设置与工作时间设置，接上大小周、休息区间、历史天数和网络校时。验收改动后首页计划节点、倒计时与计薪即时一致，重启后配置仍在。

### 阶段 3：历史统计

交付每日历史持久化、日/周/月统计视图和必要的数据兼容。验收跨午夜、午休、大小周、重复启动和应用关闭后恢复场景下金额与时长不重复、不漏计。

### 阶段 4：成就、换装、关于

交付徽章计算、装扮解锁/预览/保存、补充素材及关于页。验收达成条件后解锁状态准确，选择装扮可在首页持续显示，旧设置升级不丢数据。

### 阶段 5：整体验收

在 Windows 实际打开各页，以桌面宽屏和窄屏验收排版与交互；更新 UML、README、进度记录。Android 使用同一 QML 工程构建 APK 后做竖屏、触控、网络权限、前后台恢复验收。当前机器未安装 Android Qt Kit / SDK / NDK，因此 Android 实机验收需待工具链具备后完成。
